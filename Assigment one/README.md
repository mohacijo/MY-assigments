# Assignment One – Date Information Form

## 📌 Description
This project is a simple **C# Windows Forms Application** that allows the user to enter date information and display it as output.

The program collects:
- Day of Week
- Day
- Month
- Year

After clicking the button, the entered information is displayed on the form.

##  Features
- Enter Day of Week
- Enter Day
- Enter Month
- Enter Year
- Display the entered date information
- Clear all input fields
- Exit the application

## Example

Input:

Day of Week: Monday  
Day: 10  
Month: June  
Year: 2026

Output:

```text
Monday - 10 - June - 2026
