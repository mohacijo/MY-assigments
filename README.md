# Student Information System

------**Assigment two**
##  Description
This is a simple Student Information System developed using **C#**

The application allows the user to enter student information such as:
- Student Name
- Student ID
- Department
- Semester

After entering the information, the user can click the **Show** button to display the student details.

##  Features
- Enter student name
- Enter student ID
- Enter department
- Enter semester
- Display student information
- Clear all input fields
- Close the application
